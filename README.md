# Hackathongame---EXISTENTIAL-CRISIS
This is a hackathon project for 23-24th october 
GlitchVerse: Reality Editor
Overview
Reality Editor is a 2D puzzle-platformer built in Godot for the GlitchVerse hackathon challenge.

The player is trapped inside a corrupted virtual world and gains access to a hidden Developer Debug Console. Using powerful debugging abilities, the player manipulates the rules of reality itself to solve puzzles, overcome obstacles, and restore the game's damaged core.

Unlike traditional puzzle games, players do not simply navigate the environment. They directly alter the world's underlying logic.

Story
The game engine is collapsing.

A rogue glitch has corrupted the core systems responsible for maintaining reality. Entire sections of the world have become unstable, physics laws are breaking, and objects are disappearing without warning.

As the last remaining Debug Agent, your mission is to recover four Core Fragments hidden throughout the corrupted world and restore the Game Kernel before total system failure.

Core Mechanics
1. Object Deletion
Remove selected objects from the environment.

Examples:

Delete walls blocking a path
Remove obstacles
Clear hazards
2. Time Freeze
Temporarily freeze specific objects.

Examples:

Stop moving platforms
Freeze lasers
Halt environmental hazards
3. Gravity Manipulation
Modify gravity within sections of the level.

Examples:

Walk on ceilings
Reach hidden platforms
Reverse puzzle layouts
Level Progression
Level 1: Deleted Assets
Learn Object Deletion.

Objective:

Remove obstacles
Navigate damaged pathways
Recover Core Fragment #1
Level 2: Frozen Processes
Learn Time Freeze.

Objective:

Stop moving hazards
Manipulate timing-based puzzles
Recover Core Fragment #2
Level 3: Variable Override
Learn Gravity Manipulation.

Objective:

Traverse upside-down sections
Solve physics-based challenges
Recover Core Fragment #3
Level 4: Kernel Collapse
All mechanics combined.

Objective:

Solve advanced multi-stage puzzles
Survive a collapsing environment
Recover Core Fragment #4
Final Encounter
After collecting all four Core Fragments, the player gains access to the Game Kernel.

Instead of fighting a traditional boss, players use their debugging powers against the rogue glitch:

Delete its defenses
Freeze its attacks
Manipulate gravity to expose weak points
Restore the kernel and save reality.
